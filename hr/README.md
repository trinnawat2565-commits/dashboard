# ระบบบุคลากรและลงเวลา รพ.สต. (โฟลเดอร์ hr/)

หน้าเว็บอยู่บน GitHub Pages ส่วนข้อมูลเก็บใน Google Sheets ของผู้ดูแล ผ่าน Apps Script (`Code.gs`)

- ลงเวลาเข้า–ออกด้วย GPS (ต้องอยู่ในรัศมีที่กำหนดจาก รพ.สต.) เวลาใช้ตามเซิร์ฟเวอร์ Google
- การลา ไปราชการ (อนุมัติโดยผู้ดูแล) ตารางเวร สรุปประชุม/อบรม ทะเบียนบุคลากร ใบอนุญาต ประวัติอบรม งานที่รับผิดชอบ ประเมินผล (เห็นเฉพาะผู้ดูแล) สรุปรายเดือน และส่งออก CSV
- เข้าสู่ระบบด้วยชื่อ + PIN ของแต่ละคน

> **repo นี้เป็นสาธารณะ** ห้ามใส่ชื่อจริง PIN รูปถ่าย หรือไฟล์ข้อมูลบุคลากรลงใน repo ข้อมูลจริงทั้งหมดอยู่ใน Google Sheets เท่านั้น

## ติดตั้ง (ทำครั้งเดียว ประมาณ 15 นาที)

### 1. สร้าง Google Sheets และวางโค้ด
1. สร้างสเปรดชีตใหม่ที่ sheets.google.com ตั้งชื่อเช่น "ระบบบุคลากร รพ.สต."
2. เมนู **ส่วนขยาย > Apps Script** ลบโค้ดเดิมใน `Code.gs` แล้ววางโค้ดจากไฟล์ [`Code.gs`](Code.gs) ทั้งหมด กดบันทึก
3. เลือกฟังก์ชัน **setup** แล้วกด **เรียกใช้** อนุญาตสิทธิ์ (ถ้าขึ้นว่ายังไม่ได้ยืนยันแอป ให้กด ขั้นสูง > ไปที่โปรเจกต์)
4. จะได้ 4 ชีต: **ตั้งค่า**, **ผู้ใช้**, **ข้อมูล**, **บันทึก GPS**

### 2. ใส่รายชื่อในชีต ผู้ใช้
| รหัส | ชื่อ-สกุล | PIN | สิทธิ์ | ใช้งาน |
|---|---|---|---|---|
| S01 | (ชื่อจริง) | 4–6 หลัก | admin | ✓ |
| S02 | (ชื่อจริง) | 4–6 หลัก | staff | ✓ |

- **admin** = ผู้ดูแล อนุมัติการลา/ไปราชการ แก้ตั้งค่า ตารางเวร บันทึกเวลา และดูผลประเมินได้
- **staff** = ลงเวลาของตัวเอง ยื่นคำขอ แก้ข้อมูลของตัวเอง
- PIN จะถูกเข้ารหัสในชีตอัตโนมัติหลังเข้าสู่ระบบครั้งแรก ถ้าลืม PIN ให้พิมพ์ PIN ใหม่ทับในช่องเดิมได้เลย
- ชื่อในชีตจะถูกสร้างเป็นรายชื่อในแอปให้อัตโนมัติ (แก้ตำแหน่ง/ข้อมูลอื่นในแท็บ บุคลากร)

### 3. เผยแพร่ Apps Script เป็นเว็บแอป
1. **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่ > เฟือง > เว็บแอป**
2. ดำเนินการในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
3. คัดลอก URL ที่ลงท้ายด้วย `/exec`

### 4. ใส่ URL ใน config.js
แก้ไฟล์ [`config.js`](config.js) บน GitHub (กดรูปดินสอ) ใส่ URL ใน `apiUrl` แล้ว Commit

### 5. ตั้งพิกัด รพ.สต.
ผู้ดูแลเปิดหน้าเว็บบนมือถือ ยืนหน้าอาคาร รพ.สต. เข้าสู่ระบบ ไปแท็บ **ตั้งค่า** แล้วกด **ตั้งพิกัดตรงที่ยืนอยู่**
(ปรับรัศมีได้ ค่าเริ่มต้น 150 เมตร ปิดการตรวจพิกัดชั่วคราวได้ในชีต ตั้งค่า)
หรือพิมพ์ละติจูด/ลองจิจูดลงชีต **ตั้งค่า** ช่อง B2/B3 เองก็ได้
ถ้าต้องการให้ตั้งพิกัดได้เฉพาะบางคน ใส่รหัสในช่อง **ผู้ตั้งพิกัดได้ (รหัส)** (B7) เช่น `S02` ถ้าเว้นว่าง admin ทุกคนตั้งได้

### ลงเวลาเอง / ย้อนหลัง
เจ้าหน้าที่กดปุ่ม **ลงเวลาเอง / ย้อนหลัง** ที่การ์ดของตัวเอง ใส่วันที่และเวลาเข้า/ออก (หมายเหตุไม่บังคับ) เวลาขึ้นทันที
ตั้งค่าในชีต **ตั้งค่า**: **ลงเวลาย้อนหลังได้ (วัน)** (B8, ค่าเริ่มต้น 7, ใส่ 0 เพื่อปิด) และ **ย้อนหลังต้องให้ admin อนุมัติ** (B9, ค่าเริ่มต้นไม่ติ๊ก ถ้าติ๊ก คำขอจะรอ admin อนุมัติในแท็บ วันนี้)
ทุกครั้งที่ลงเวลาเองถูกบันทึกในชีต บันทึก GPS เพื่อตรวจย้อนหลัง

### 6. แจกลิงก์
ส่งลิงก์ `https://<ชื่อบัญชี>.github.io/dashboard/hr/` ในกลุ่ม LINE แนะนำให้กด "เพิ่มไปยังหน้าจอหลัก"

## เมื่อแก้ Code.gs ภายหลัง
**ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > แก้ไข > เวอร์ชันใหม่** URL เดิมจึงจะได้โค้ดใหม่

## ข้อจำกัด
- แอปปลอมตำแหน่ง GPS ยังหลอกระบบได้ ทุกการกดลงเวลาถูกเก็บไว้ในชีต บันทึก GPS พร้อมพิกัดและระยะห่าง ควรสุ่มตรวจ
- ถ้าบอก PIN ให้คนอื่น คนนั้นลงเวลาแทนได้ (ถ้าอยู่ในพื้นที่)
- ข้อมูลอัปเดตระหว่างเครื่องทุก 30 วินาที
- ปุ่ม "ให้ Claude ช่วยเรียบเรียง" ในสรุปประชุมใช้ได้เฉพาะเวอร์ชันบน claude.ai จึงถูกซ่อนในเวอร์ชันนี้
