ไฟล์ CSV เปิดใน Excel ได้ภาษาไทยถูกต้อง มี 1 แถวต่อผู้เข้าร่วม 1 รอบ รวมข้อมูลส่วนที่ 1 และค่าที่คำนวณแล้ว ไม่มีชื่อหรือข้อมูลติดต่อตามข้อกำหนดของแบบสอบถาม

ฐานข้อมูลเชื่อมกับ Google Sheets

  1. สร้าง Google Sheet ใหม่ แล้วเปิดเมนู ส่วนขยาย → Apps Script
  2. ลบโค้ดเดิม วางโค้ดจากไฟล์ apps-script.gs แล้วแก้ SECRET เป็นรหัสลับของคุณเอง กดบันทึก
  3. กด ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป ตั้ง "เรียกใช้ในฐานะ" เป็น ฉัน และ "ผู้มีสิทธิ์เข้าถึง" เป็น ทุกคน แล้วกดอนุญาตสิทธิ์
  4. คัดลอก URL ของเว็บแอป (ลงท้ายด้วย /exec) มาวางด้านล่าง พร้อมรหัสลับ

ลิงก์และรหัสลับจะจำไว้ในเบราว์เซอร์นี้เท่านั้น ไม่ได้อยู่ในหน้าเว็บหรือ GitHub แต่ละเครื่องต้องใส่ครั้งแรกครั้งเดียว ห้ามเผยแพร่ลิงก์นี้ เพราะใครมีลิงก์และรหัสลับจะอ่านและแก้ข้อมูลได้

สำรองไฟล์สำรองข้อมูล

ดาวน์โหลดข้อมูลทั้งหมดเป็นไฟล์ JSON เก็บไว้ หรือนำเข้าเพื่อย้ายข้อมูลไปเครื่องอื่น
