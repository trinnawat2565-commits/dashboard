# แดชบอร์ดลดละเลิกเหล้า

หน้าเว็บเก็บข้อมูลตามแบบสอบถาม ALT/AST, AUDIT, HLQ20 และความพร้อมงดดื่ม (7 ส่วน) พร้อมแดชบอร์ดสรุปผลรอบตั้งต้นเทียบรอบติดตาม

เปิดใช้งาน: `https://trinnawat2565-commits.github.io/dashboard/alcohol-survey/`

## ไฟล์

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `index.html` | หน้าเว็บทั้งหมด (ฟอร์ม แดชบอร์ด รายการบันทึก ตั้งค่า) |
| `apps-script.gs` | โค้ดสำหรับวางใน Google Apps Script เพื่อใช้ Google Sheets เป็นฐานข้อมูลกลาง |
| `demo.json` | ข้อมูลสมมุติ 12 คน (รหัส DEMO-…) ใช้ดูหน้าตาแดชบอร์ด |

## ข้อมูลเก็บที่ไหน

- **ยังไม่ได้เชื่อม Google Sheets**: ข้อมูลอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น
- **เชื่อม Google Sheets แล้ว** (แท็บ "ตั้งค่า"): ทุกเครื่องที่ใส่ Web app URL และรหัสลับเดียวกันจะเห็นข้อมูลชุดเดียวกัน

repo นี้เป็นสาธารณะ ห้าม commit ข้อมูลผู้เข้าร่วมจริง, Web app URL หรือรหัสลับลงใน repo
